# Code Connect — navegação com React Router

Aplicação de comunidade para pessoas desenvolvedoras, com feed de publicações, páginas de artigo e fluxos de autenticação. Esta versão concentra-se na navegação entre telas usando React Router.

## Funcionalidades

- Feed de publicações e página de detalhes
- Telas de login e cadastro
- Rotas protegidas e layouts para autenticação e aplicação
- Componentes reutilizáveis para autores, comentários e publicações

## Tecnologias

React, JavaScript, React Router, Vite e CSS Modules.

## Como executar

```bash
npm install
npm run dev
```

O Vite informa no terminal o endereço local da aplicação. Para criar a build de produção, execute `npm run build`.

## Contexto

Projeto educacional desenvolvido durante estudos de React Router.
